# Основи IP-адресації та статичної маршрутизації

Лабораторна робота з курсу комп'ютерних мереж. Проєкт присвячений розрахунку параметрів підмереж за допомогою безкласової адресації (CIDR), налаштуванню статичної маршрутизації та моделюванню мережевої топології у середовищі **Cisco Packet Tracer**.

## Мета роботи

Ознайомлення з призначенням, структурою і типами IP-адрес,
навчитись працювати з адресацією у IP мережах; придбання вмінь розбивки IP –
мережі на підмережі; придбання вмінь налаштування параметрів стеку TCP/IP на
робочій станції в ОС Windows і Unix; придбання вмінь налаштування статичної
маршрутизації та досвіду моделювання у пакеті Cisco Packet Tracer.

## Варіант завдання

Для варіанта №2 групи КН-31 виділено два блоки адрес:

- **Блок 1:** `8.111.2.0/16` — розбиття на 4 рівні підмережі з новою маскою `/18`;
- **Блок 2:** `132.161.0.0/26` — розбиття на 4 рівні підмережі з новою маскою `/28`.

Отримані підмережі:

```text
Блок 1 (маска 255.255.192.0 /18):
- 8.111.0.0/18   (діапазон хостів: 8.111.0.1 – 8.111.63.254)
- 8.111.64.0/18  (діапазон хостів: 8.111.64.1 – 8.111.127.254)
- 8.111.128.0/18 (діапазон хостів: 8.111.128.1 – 8.111.191.254)
- 8.111.192.0/18 (діапазон хостів: 8.111.192.1 – 8.111.255.254)

Блок 2 (маска 255.255.255.240 /28):
- 132.161.0.0/28  (діапазон хостів: 132.161.0.1 – 132.161.0.14)
- 132.161.0.16/28 (діапазон хостів: 132.161.0.17 – 132.161.0.30)
- 132.161.0.32/28 (діапазон хостів: 132.161.0.33 – 132.161.0.46)
- 132.161.0.48/28 (діапазон хостів: 132.161.0.49 – 132.161.0.62)

Транзитна мережа «точка-точка» (маска 255.255.255.252 /30):
- 132.161.0.64/30 (Router1: 132.161.0.65, Router0: 132.161.0.66)
```

## Використані пристрої та топологія

- **Маршрутизатори:** `Router0` обслуговує Блок 1, `Router1` — Блок 2;
- **Комутатори:** комутатори серії Cisco Catalyst 2960 для кожного сегмента підмережі;
- **Кінцеві пристрої:** робочі станції `PC0–PC7` у підмережах Блоку 1 та `PC8–PC11` у підмережах Блоку 2;
- **З'єднання:** канал типу «точка-точка» між маршрутизаторами через підмережу `132.161.0.64/30`.

## Запуск і перевірка

Відкрийте файл `topology.pkt` у Cisco Packet Tracer. Для перевірки зв'язку між різними сегментами мережі на робочій станції `PC8` відкрийте **Desktop → Command Prompt** і виконайте:

```bash
ping 8.111.0.2
tracert 8.111.0.2
```

Очікуваний результат виконання `tracert`:

```text
Tracing route to 8.111.0.2 over a maximum of 30 hops:

  1   <1 ms    <1 ms    1 ms     132.161.0.14
  2    0 ms     0 ms    0 ms     132.161.0.66
  3   11 ms    10 ms   10 ms     8.111.0.2

Trace complete.
```

Перевірка ехо-запиту безпосередньо з маршрутизатора `Router0` до віддаленого клієнта:

```text
Router# ping 132.161.0.18
Sending 5, 100-byte ICMP Echos to 132.161.0.18, timeout is 2 seconds:
!!!!!
Success rate is 100 percent (5/5), round-trip min/avg/max = 0/0/0 ms
```

## Особливості реалізації

- Виконано оптимізацію адресного простору методом запозичення бітів хостової частини для утворення фіксованих підмереж однакового розміру.
- На обох граничних маршрутизаторах налаштовано маршрути за замовчуванням (`0.0.0.0/0`) для агрегації міжмережевого трафіку без внесення надлишкових записів до таблиць маршрутизації.
- У режимі симуляції (**Simulation Mode**) досліджено повний життєвий цикл передавання пакетів, зокрема формування початкового ARP-запиту для пошуку MAC-адреси шлюзу перед надсиланням першого ICMP-пакета.
- Підтверджено коректне зменшення значення поля TTL на кожному транзитному кроці (хопі) маршрутизатора.
