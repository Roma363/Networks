# Комп'ютерні мережі — лабораторні роботи

Репозиторій містить лабораторні роботи з курсу **«Комп'ютерні мережі»**. Матеріали охоплюють передавання даних через TCP/UDP, аналіз мережевого трафіку у Wireshark, IP-адресацію та статичну маршрутизацію, налаштування прикладних сервісів TCP/IP і використання мережевих утиліт операційної системи.

## Зміст репозиторію

| Лабораторна робота | Опис | Матеріали |
|---|---|---|
| **Лабораторна робота 1** | Передавання структурованих даних між клієнтом і сервером через TCP та UDP | [Перейти до проєкту](lab-1/) |
| **Лабораторна робота 2** | Аналіз перехопленого мережевого трафіку та життєвого циклу TCP-сеансу у Wireshark | [Перейти до проєкту](lab-2/) |
| **Лабораторна робота 3** | Розрахунок підмереж, IP-адресація та статична маршрутизація у Cisco Packet Tracer | [Перейти до проєкту](lab-3/) |
| **Лабораторна робота 3а** | Налаштування DHCP, DNS, FTP та HTTP у локальній мережі | [Перейти до проєкту](lab-3a/) |
| **Лабораторна робота 4** | Дослідження мережевих утиліт Windows для аналізу та діагностики мережі | [Перейти до проєкту](lab-4/) |

## Теми, що досліджуються

- принципи роботи протоколів **TCP** та **UDP**;
- передавання даних через клієнт-серверні сокети;
- структура пакетів і рівні моделі **OSI**;
- аналіз протоколів **Ethernet, ARP, IPv4, IPv6, TCP, UDP, HTTP, DNS, QUIC і TLS**;
- безкласова IP-адресація (**CIDR**) та розбиття мереж на підмережі;
- налаштування статичної маршрутизації у **Cisco Packet Tracer**;
- робота прикладних мережевих служб **DHCP, DNS, FTP та HTTP**;
- діагностика мережі за допомогою `ping`, `tracert`, `ipconfig`, `arp`, `route`, `netstat`, `hostname` і `whois`;
- визначення MTU, маршрутів, TTL, затримок і станів TCP-з'єднань.

## Вимоги

Залежно від лабораторної роботи можуть знадобитися:

- Linux, WSL або інше POSIX-сумісне середовище;
- компілятор GCC і стандарт C11;
- Cisco Packet Tracer версії 8.0 або новішої;
- Wireshark;
- Windows із `cmd` або PowerShell;
- доступ до мережі Інтернет;

Детальні інструкції з підготовки середовища, запуску та перевірки наведено у `README.md` відповідної лабораторної роботи.

У каталогах лабораторних робіт можуть міститися:

- `README.md` — опис завдання, конфігурації, запуску та результатів;
- `protocol.pdf` — повний звіт із розрахунками, скриншотами та висновками;

- вихідні файли програм і спільні заголовки для лабораторної роботи з TCP/UDP.
