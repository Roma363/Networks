# Передача даних через TCP та UDP

Лабораторна робота з курсу комп'ютерних мереж. Проєкт демонструє передачу набору чисел між клієнтом і сервером за допомогою протоколів **TCP** та **UDP**.

## Варіант завдання

Для варіанта №2 групи КН-31 потрібно передати:

- 4 числа типу `float`;
- 2 числа типу `int`.

Дані описані структурою `TaskData` у файлі `data.h`:

```c
typedef struct {
    float numbers_float[4];
    int numbers_int[2];
} TaskData;
```

Клієнти передають такі значення:

```text
float: 1.1, 2.2, 3.3, 4.4
int:   100, 200
```

## Структура проєкту

| Файл | Призначення |
|---|---|
| `data.h` | Спільне оголошення структури переданих даних |
| `tcp_server.c` | TCP-сервер: приймає та виводить дані |
| `tcp_client.c` | TCP-клієнт: підключається до сервера та передає дані |
| `udp_server.c` | UDP-сервер: приймає та виводить датаграму |
| `udp_client.c` | UDP-клієнт: надсилає датаграму на локальний сервер |

## Використані порти

- TCP — порт `8080`;
- UDP — порт `8081`.

TCP-клієнт і UDP-клієнт підключаються до локального сервера за адресою `127.0.0.1`.

## Вимоги

Для компіляції потрібні:

- Linux, WSL або інше POSIX-сумісне середовище;
- компілятор GCC;
- стандарт C11 або сумісний.

Код використовує заголовки POSIX-сокетів:

```c
#include <unistd.h>
#include <arpa/inet.h>
```

Тому безпосередня компіляція стандартним Windows-компілятором може бути неможливою без адаптації під Winsock.

## Компіляція

Відкрийте термінал у каталозі проєкту та виконайте:

```bash
gcc -Wall -Wextra -std=c11 tcp_server.c -o tcp_server
gcc -Wall -Wextra -std=c11 tcp_client.c -o tcp_client
gcc -Wall -Wextra -std=c11 udp_server.c -o udp_server
gcc -Wall -Wextra -std=c11 udp_client.c -o udp_client
```

## Запуск TCP

У першому терміналі запустіть сервер:

```bash
./tcp_server
```

Після появи повідомлення про очікування підключення у другому терміналі запустіть клієнт:

```bash
./tcp_client
```

Очікуваний результат сервера:

```text
TCP Server listening on port 8080...
Received TCP Data:
Float[0]: 1.10
Float[1]: 2.20
Float[2]: 3.30
Float[3]: 4.40
Int[0]: 100
Int[1]: 200
TCP Transfer Time: ... ms
```

## Запуск UDP

У першому терміналі запустіть UDP-сервер:

```bash
./udp_server
```

У другому терміналі запустіть UDP-клієнт:

```bash
./udp_client
```

Очікуваний результат сервера:

```text
UDP Server listening on port 8081...
Received UDP Data:
Float[0]: 1.10
Float[1]: 2.20
Float[2]: 3.30
Float[3]: 4.40
Int[0]: 100
Int[1]: 200
UDP Receive Time: ... ms
```

## Особливості реалізації

- TCP-клієнт і сервер використовують потоковий сокет `SOCK_STREAM`.
- UDP-клієнт і сервер використовують датаграмний сокет `SOCK_DGRAM`.
- Для TCP реалізовано циклічне передавання та приймання всієї структури, оскільки TCP не гарантує відповідність одного `send()` одному `read()`.
- Для UDP перевіряється результат `sendto()` та `recvfrom()`.
- Сервери перевіряють, що отримано повний обсяг структури `TaskData`.
- Програми працюють з клієнтом і сервером на одному локальному комп'ютері.
